# C4 Level 4 – Code Overview

This level lists the main code elements only.

- `class Graph` – represents the graph.
- `def bfs()` – performs Breadth-First Search.
- `def dfs()` – performs Depth-First Search.
- `def reconstruct_path()` – creates the final route from parent information.
- `def read_input()` – accepts user/search input.
- `def display_result()` – prints the output.

Large source code is intentionally not included in the Code-level architecture view.
